ブラウザで遊べる、『真・三國無双』風のボクセルアクションゲームです。Three.js で制作しています。もとは「趙雲が約 300 人の魏軍に単騎で挑む」デモでしたが、現在は **4 勢力の指揮官ゲーム** に発展しました。武将と軍勢を率いて自陣の旗を守り、中央の旗を奪い、ライバルの旗を切り倒します。相手はコンピューターでも、最大 3 人の友達でも構いません。

ビルド不要：素の ES モジュール構成で、Three.js r186 は `vendor/three/` に同梱。シミュレーションは固定 60 Hz の決定論的ステップで動作します。

## ゲームモード

| モード | 内容 |
| --- | --- |
| **フレンドルーム** | 6 桁のコードでルームを作成／参加。最大 4 人。順番に勢力を選び（1 人 10 秒）、続いて武将を選びます（15 秒）。1 人のブラウザがシミュレーションを担当し、小さな中継サーバー（`server/`）が全員をつなぎます。 |
| **対コンピューター（PvE）** | あなた + AI 1〜3 人。AI は残りの勢力と武将をランダムに選びます。かんたん／ふつう／むずかしい（反応時間 1.0 / 0.5 / 0.25 秒、収入 ×0.8 / ×1.0 / ×1.2）。 |
| **ひとりで練習** | 動かない敵武将を相手にした通常の 1 試合。ショップ、号令、旗の練習に最適です。 |
| **無双デモ（クラシック）** | 元の単騎デモ：趙雲 vs 魏軍の大群。 |

### ルールの要点

- 1 試合は **15 分**。各プレイヤーは **旗（1 500 HP）** を持ち、倒されると脱落します。**相手全員の旗を切り倒せば即勝利**（切るたびに +1 000 ゴールド）。時間切れなら **獲得ゴールド合計が最大** のプレイヤーの勝ち（同点は引き分け）。
- **中央の旗**：4 m 以内に 5 秒間立ち続ける（妨害なし）と奪取でき、保持者の収入が **×1.5** になります。
- 収入は毎秒 10 ゴールド（初期 300）。**ショップ**（`B`）で、単体の兵（槍／剣盾／弓、50 ゴールド）、**小隊コンボ**（13 人、500 ゴールド）、最大 8 人の盾槍 **旗の守衛**、**強化**（レベル 2〜3、300 / 600 ゴールド）を購入できます。機動兵力は最大 60。相性は 槍 > 弓 > 剣盾 > 槍（ダメージ ×1.5）。
- 4 つの **号令** で軍を指揮します：追従、防御、攻撃、撤退（`1`〜`4`）。
- 武将が倒れると配下は消えますが、旗の守衛・ゴールド・強化は残ります。10 秒後に中隊長と旗手を連れて復活し、待機中に購入した兵は復活時に現れます。

## 特徴

- クラシックなアクション：流れるような通常コンボ（N1–N6）とチャージ攻撃（C1–C6）、ヒットストップとヒットエフェクト
- 4 勢力（魏・蜀・呉・黄巾）に固有の色と旗、選べる武将は 20 人（専用モデル／技を持つのは今のところ趙雲のみで、他の武将は当面それを流用）
- ボクセルの兵士による軍勢（InstancedMesh）：陣形、ターゲット選択、相性、4 つの号令
- 経済、ショップ、強化、旗、中央旗、復活、ミニマップ、リザルト画面
- AI 対戦相手（ゴールドを使い号令を出す指揮官 + 簡易ステートマシンの武将）
- 最大 4 人のオンラインルーム（ホスト権威型、20 Hz スナップショット、60 秒以内なら再接続可）
- ベトナム語／英語のインターフェース（タイトル画面で切り替え）
- 夕暮れの城塞戦場、独自のポストプロセス（かすみ、被写界深度、ブルーム、レトロなピクセル表現）、WebAudio によるプロシージャルサウンド、書道風 HUD

## 起動方法

ES モジュールは `file://` から読み込めないため、任意の静的サーバーでフォルダを配信してください。

```sh
python3 -m http.server 8000
```

その後 http://localhost:8000 を開きます。WebGL2 対応ブラウザが必要で、デスクトップ GPU 推奨です。サウンドは最初のキー入力またはクリックで開始します。

### オンラインルーム（任意）

ルームには中継サーバー（Node.js 18 以上、依存は `ws` のみ）が必要です。`src/` の共通設定も読み込むため、リポジトリのルートで実行してください。

```sh
npm install --prefix server
npm run server          # :8787 で待ち受け、GET /health → ok
```

`localhost` でページを開くと `ws://localhost:8787` に自動で接続します。デプロイ済みのサーバーを使う場合は `?server=wss://あなたのサーバー` を付けて開く（または `src/net/client.js` の `DEFAULT_SERVER_URL` を設定）。デプロイ手順と Render 用設定は [`server/DEPLOY.md`](server/DEPLOY.md)、[`render.yaml`](render.yaml) を参照。ホストのブラウザタブは前面に出したままにしてください——バックグラウンドで速度制限を受けるとルーム全体が重くなります。

### テスト

```sh
npm test
```

Node のテスト（ルール、経済、軍勢、AI、ネットワークプロトコル、ルーム、多言語）を実行します。WebSocket のテストは Node 組み込みの `WebSocket` を使うため、Node 22 以上を推奨します。

## 操作方法

キーボードとマウス。ゲームパッドも利用できます。

| 操作 | キー |
| --- | --- |
| 移動（カメラ基準） | WASD / 矢印キー |
| 通常攻撃 | J / 左クリック（J を 3 回連続で押すと 3 回目が自動でチャージ攻撃に） |
| チャージ攻撃 | K / 右クリック |
| カメラ回転 | マウスドラッグ / Q E |
| 回復薬 | R（5 本、1 本で最大 HP の 30% 回復。使い切ったら自陣の旗、または保持している中央の旗まで戻ると補充） |
| 号令：追従 / 防御 / 攻撃 / 撤退 | 1 / 2 / 3 / 4（ゲームパッドは十字キー） |
| ショップ | B（試合は止まりません） |
| ポーズ / メニュー | Esc（オンライン対戦中はゲームが止まりません） |
| 開始 | Enter / 出陣 をクリック |

攻撃ボタンは J と K の 2 つだけです。すべての武将でジャンプ・回避・無双を無効にしています（入力は `src/hero/controls.js` で一括フィルタ）。

## オプション

| URL パラメータ | 説明 |
| --- | --- |
| `?enemies=N` | 無双デモの敵兵数、0〜2000（既定 300） |
| `?server=wss://…` | ルームサーバーのアドレス（localhost では既定で `ws://localhost:8787`） |
| `?mode=sandbox` | 「ひとりで練習」の試合に直接起動 |
| `?gold=N`、`?nodef=1`、`?flaghp=N` | 試合のテスト用：初期ゴールド、敵の守備兵なし、旗の HP |
| `?debug=1`、`?norender=1` | 開発者向け（`window.__game`、`__ff(n)`）。描画を省略し、GPU なしでもシミュレーションを全速で実行 |
